# Proactive contact release

Version: 0.1.7. Requires the compatible gateway first. Explicit proactive topics carry `proactive: true`; confirmed task endings without existing process records publish a durable terminal activity. Ordinary replies and individual tool failures do not become contact events. Include the approved Responses connection compatibility and shared Claude-aware protocol additions without changing native versions, permissions, supervisor trust, canary scope or retry policy.

Installation requires the protected signing workflow and verification against independently trusted keys. A source tag alone is not proof of an installed or signed release. Busy hosts must not be interrupted.
